# StudentManagement

Angular frontend for the Student Management system.

## Development server

```bash
npm install
npm start
```

Open `http://localhost:4200/`. The app reloads automatically when you change source files.
The API URL is configured in `src/environments/environment.ts`.

## Building

```bash
npm run build
```

Build artifacts are written to `dist/student-management`.

## Running unit tests

```bash
npm test
```
